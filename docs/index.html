Política de Privacidade

Resume Podcast - JN · Última atualização: 9 de julho de 2026

Esta Política de Privacidade descreve como a extensão Resume Podcast - JN trata informações quando você a utiliza no navegador Google Chrome.

1. Sobre a extensão

Resume Podcast - JN é uma extensão independente, sem vínculo oficial com o Jovem Nerd. Seu único propósito é salvar e restaurar o progresso de reprodução de podcasts no site jovemnerd.com.br.

2. Dados coletados

A extensão armazena localmente, no navegador do usuário, apenas as seguintes informações:

  • URL do episódio de podcast em reprodução
  • Título do episódio
  • Posição de reprodução (minutagem)
  • Data e hora da última atualização do progresso

Esses dados são salvos no localStorage do domínio jovemnerd.com.br e permanecem exclusivamente no dispositivo do usuário.

3. Dados que não são coletados

A extensão não coleta, transmite nem armazena:

  • Nome, e-mail ou qualquer dado de identificação pessoal
  • Histórico de navegação fora do contexto do player de podcast
  • Dados de contas ou logins
  • Informações financeiras
  • Localização

4. Compartilhamento de dados

A extensão não envia dados para servidores externos, APIs de terceiros, serviços de análise ou qualquer outro destino fora do navegador do usuário.

5. Permissões utilizadas

A extensão acessa exclusivamente o domínio jovemnerd.com.br para identificar o player de podcast da página e salvar ou restaurar o progresso de reprodução. Nenhuma outra permissão é solicitada.

6. Retenção e exclusão dos dados

Os dados permanecem no dispositivo até que:

  • O usuário inicie a reprodução de outro episódio (o progresso anterior é removido)
  • O usuário limpe os dados do site jovemnerd.com.br nas configurações do navegador
  • O usuário desinstale a extensão

7. Código remoto

A extensão não utiliza código remoto. Todo o código necessário para seu funcionamento está incluído no pacote da extensão instalada no navegador.

8. Menores de idade

A extensão não coleta intencionalmente dados pessoais de menores de idade e não exige cadastro ou identificação do usuário.

9. Alterações nesta política

Esta política pode ser atualizada periodicamente. A data da última atualização será revisada no topo desta página quando houver mudanças.

10. Contato

Em caso de dúvidas sobre esta Política de Privacidade, entre em contato pelo repositório do projeto no GitHub: github.com/andremrod/resumepodcast-jn.github.io
